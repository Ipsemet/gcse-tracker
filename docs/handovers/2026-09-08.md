## Bugs found and fixed during the build

1. **Planner scheduled the same topic every day.** Every future day was generated from the same
   mastery snapshot, so all picked the same weakest topic. Fixed by threading `avoidTopicIds`
   through `ensurePlan`/`regenerateDay` so the horizon advances through the spec.
2. **Future days quoted today's due-card count.** A day two weeks out claimed "1 card due".
   Future days now get a generic review block at a moderate weight.
3. **Short days wasted leftover capacity.** A 45-minute evening scheduled one 30-minute block and
   dropped the rest. Slots now shorten to fit, down to a 15-minute floor.
4. **Review blocks were a fixed 30 minutes** regardless of deck size. Now sized from the number of
   cards in rotation.
5. **"Easy" on a new flashcard** still walked it through the learning steps. It now graduates
   immediately.
